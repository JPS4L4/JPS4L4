### 🚀 About Me

- 💼 Since September 2026 I'm a **full-stack developer at Consolidando Propiedades**, working on a multi-tenant SaaS CRM: a NestJS microservices monorepo (NATS, Prisma, PostgreSQL) and a Next.js 15 frontend.
- 🎬 I build its file and video module end to end: the **HLS transcoding worker** (1080p/720p ladder, 720p published first), timestamp-anchored video comments, resumable multipart uploads and a keyboard-driven file explorer.
- ✨ I care about the details users feel: motion, empty and loading states, accessibility and keyboard shortcuts.
- 🤖 Background in **RPA and process automation** (Python, Power Automate, Excel VBA) and dashboards with **Power BI**.
- 🎓 Studying **Data Science Engineering** at ITM (Instituto Tecnológico Metropolitano).
- 🌍 Based in Bello, Antioquia, Colombia
